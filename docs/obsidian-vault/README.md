# Enkodu Obsidian Vault

This folder is an Obsidian-ready vault for the YuliaAV1 / Enkodu project.

Open `docs/obsidian-vault` as a vault in Obsidian, then start at [[Home]].

The vault documents:

- Current architecture and code reality.
- Queue, worker, companion flows.
- Platform readiness.
- Limited-release gaps.
- Operational runbooks.
- Risks and open questions.

Sensitive deployment details still live outside the repo in `~/.agentSecrets/enkodu/secrets.md`. Do not copy credentials, private tokens, or private deploy-only values into this vault.
